**What problem am I solving?**

Organizations often spend significant time searching across scattered documents, reports, code, and datasets to find reliable information and make decisions. Existing search tools frequently return too much irrelevant information or require users to know exactly where to look.
Researchers spend considerable time cleaning data, preparing datasets, performing exploratory analysis, creating dashboards, conducting statistical analyses, and writing reports.
So I am going to build an AI Analytics Agent that helps users quickly find, understand, and summarize information from multiple data sources, enabling faster and more informed decision-making.


**Why is this important?**
Modern organizations are overwhelmed by information. Finding the right knowledge quickly is becoming increasingly difficult, leading to lost time and slower decision-making. An AI assistant that can understand documents and answer questions from reliable sources helps teams work more efficiently, make better decisions, and unlock greater value from their existing data.

**Who are the users?**

Initially:
Biomedical researchers.

Later:
Data analysts.

**What should Version 1 do?**
- Upload CSV
- Check data quality
- Clean data
- Preprocess
- EDA
- Dashboard
- Statistical analysis
- Generate report
